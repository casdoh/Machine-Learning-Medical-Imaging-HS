# Project Overview

## Background

Hidradenitis suppurativa (HS) is a chronic inflammatory skin disease characterised by painful nodules, abscesses and sinus tract formation. Its underlying mechanisms remain poorly understood, with increasing evidence implicating both innate and adaptive immune pathways.

## Aim

This project investigated the spatial organisation of inflammatory and immune markers in HS tissue using high-resolution fluorescence microscopy, quantitative image analysis and machine learning.

## Objectives

1. Quantify immune marker expression in lesional and normal tissue.
2. Investigate the spatial localisation and colocalisation of inflammatory markers.
3. Characterise immune cell populations within HS tissue.
4. Apply machine learning to classify markers and identify spatial patterns.

## Key Findings

Lesional tissue showed increased inflammasome proteins, T- and B-cell infiltration, complement deposition and quinolinic acid. Spatial analysis identified distinct inflammatory niches within HS lesions.

Machine learning models including SVM, kNN, Random Forest and XGBoost achieved ROC-AUC values of 0.70–0.95 when classifying marker and tissue characteristics.
